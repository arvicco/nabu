  llms-full.txt (https://llmstxt.org): every page of the site navigation as
  plain text, for an agent that wants the whole site in one read. Rendered
  at build time from each page's own rendered content, so every figure is
  the one that page renders from the census SSOT — this template states
  none. The file name sorts after every page it reads ON PURPOSE: Jekyll
  renders site.pages in file-name order, and a page's content is rendered
  HTML only once its own turn has passed (test/site/agent_discovery_test.rb
  guards the ordering). News is left out: it is a dated archive, linked
  from llms.txt.
{%- endcomment -%}
