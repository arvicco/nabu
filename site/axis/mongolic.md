## Working the mongolic desk

The generic desk surfaces — every desk answers to these, in working
order (enable once, sync, then query):

```
nabu enable mongolic               # first time: put this desk's shelves in this box's profile
nabu sync mongolic                 # fetch/refresh the desk's enabled members
nabu list --axis mongolic          # the shelf census, this desk only
nabu axis mongolic                 # the desk card: members, holdings, gold coverage
nabu search WORD --axis mongolic   # a query scoped to this desk's shelves
```
