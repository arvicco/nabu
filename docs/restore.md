# Restoring Nabu on a fresh box

Everything derived is rebuildable; everything permanent lives in three
places. This page is the whole restore doctrine.

## What is permanent

- **`canonical/`** — the library's asset: every fetched source, every
  module's reference data, and the owner-authored shelves
  (local-source/local-language/local-place dossiers, notes).
- **`db/lects.sqlite3`** — the enrichment journal (per-document lect
  rulings). The ONE file under `db/` that is not derived.
- **Config**: `config/nabu.yml` (if customized) and the box's
  enablement profile (`config/profile.yml`).

Everything else under `db/` — the catalog, the fulltext/derived
indexes (FTS, lemma index, char postings, place index) — is a pure
function of the above and is regenerated by `nabu rebuild`.

## Path 1 — carry the assets (minutes)

1. Clone the repo, `bundle install`.
2. Copy `canonical/`, `db/lects.sqlite3`, and your config/profile from
   the old box (or from backup).
3. `bin/nabu rebuild` — one command re-derives the catalog, the
   fulltext index, and every derived lane (timeline, facets, place
   index and apply, char postings). Done.

## Path 2 — fresh from upstreams

1. Clone, `bundle install`, **`bin/nabu quickstart`** — the CORE group
   (nabu-lects · nabu-places · cigs, the registry instruments) syncs
   automatically, pre-enabled; the starter shelf follows.
2. **Capability groups** — a group name expands for both commands:
   - `bin/nabu enable signs && bin/nabu sync signs` restores the whole
     sign/character capability: the two identity-spine modules (osl,
     unikemet — machinery, no enablement) plus the Han card's shelves,
     the reading lanes, and the Wiktionary sense lane.
3. **Everything else is enable-then-sync per source or per axis**
   (`nabu enable germanic && nabu sync germanic`). Grant-gated sources
   additionally need their grant recorded (the sync explains).
4. Corpus-scale attestation panels (the char cards' corpus lines, the
   place desk's holdings) count whatever is held — sync the corpora
   you care about, in any order.

Manual-Adapter sources (trismegistos-geo, and any source whose
upstream only a human can download) print their acquisition
instruction card at sync until you drop the file in `incoming/<slug>/`
— nothing fails, nothing is skipped silently.

## The one rule that makes order irrelevant

Every desk degrades **section by section, honestly**: an unsynced
shelf is an absent section, an unbuilt index is a "not indexed yet"
hint, an unheld gazetteer is a sync note — never an error, never a
placeholder. There is no wrong sequence; there is only more or less of
the library present.
